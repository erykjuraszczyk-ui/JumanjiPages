# JUMANJI 2.111.1 — Website

Polskojęzyczna, responsywna strona zapowiadająca projekt gry. Zbudowana w czystym HTML, CSS i JavaScript — bez frameworka i bez procesu kompilacji.

## Uruchomienie lokalne
Otwórz `index.html` w przeglądarce albo uruchom `python3 -m http.server 8080` w katalogu projektu.

## GitHub Pages
Repozytorium zawiera workflow `.github/workflows/pages.yml`. W GitHub przejdź do **Settings → Pages** i ustaw źródło publikacji na **GitHub Actions**. Każdy push do `main` uruchomi wdrożenie.

## Struktura
- `index.html` — treść i sekcje strony
- `styles.css` — responsywny wygląd
- `script.js` — menu mobilne i rok w stopce
- `assets/` — autorska grafika SVG i favicon

## Status projektu
To strona zapowiadająca projekt koncepcyjny. Nie oznacza wydania gry ani potwierdzenia gotowości funkcji, trybów online czy wersji Android/Windows. Opisy platform i rozgrywki są planami projektu i mogą się zmienić.
